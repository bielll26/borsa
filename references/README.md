# References Folder

This folder contains all your reference materials that the 10X Content Expert uses to create personalized, high-quality content.

## Folder Structure

```

├── transcripts/          # Video, audio, and meeting transcripts
│   ├── training/         # Training sessions, courses
│   ├── interviews/       # Expert interviews
│   ├── webinars/         # Recorded webinars
│   ├── podcasts/         # Podcast episode transcripts
│   └── meetings/         # Meeting recordings
├── examples/             # High-performing content examples
│   ├── emails/           # Best emails to learn from
│   │   ├── welcome/      # Welcome sequence examples
│   │   ├── sales/        # Sales emails
│   │   └── newsletters/  # Newsletter examples
│   ├── social/           # Top social media posts
│   │   ├── linkedin/     # LinkedIn posts
│   │   ├── twitter/      # Twitter posts/threads
│   │   └── instagram/    # Instagram captions
│   ├── presentations/    # Excellent PPT examples
│   └── blogs/            # Top-performing articles
├── brand-voice/          # Brand guidelines
│   ├── tone-guide.md     # Voice and tone documentation
│   ├── messaging-framework.md
│   ├── keywords.txt      # Power words and phrases

├── templates/            # Content templates
│   ├── email/
│   ├── social/
│   ├── ppt/
│   └── blog/
└── competitors/          # Competitor content analysis
    └── [competitor-name]/
```

## How to Add References

### Transcripts

1. Get transcripts from your videos, webinars, or podcasts
2. Save as `.txt` or `.md` files
3. Place in the appropriate subfolder
4. Use descriptive names: `2024-01-15_product_launch_webinar.txt`

**Tip:** Tools like Otter.ai, Descript, or YouTube's auto-transcribe can help create transcripts.

### Content Examples

Add your best-performing content to learn from:
- Copy your top LinkedIn posts to `examples/social/linkedin/`
- Save winning email copy to `examples/emails/`
- Add successful blog posts to `examples/blogs/`

Include metadata when possible:
```
# Post: [Title]
# Platform: LinkedIn
# Date: 2024-01-15
# Performance: 50K views, 500 comments

[Content here]
```

### Brand Voice

Create your brand guidelines:

**tone-guide.md** - Document your brand personality:
```markdown
# Brand Voice Guide

## Personality
We are: confident, approachable, expert
We are NOT: stuffy, salesy, boring

## Tone by Context
- Social media: Conversational, engaging
- Email: Personal, helpful
- Sales: Confident, value-focused
```

**keywords.txt** - Words you love to use:
```
transform
proven
unlock
accelerate
```

**avoid-list.txt** - Words to never use:
```
synergy
leverage (as verb)
disrupt
```

## Best Practices

1. **Quality over quantity** - A few excellent examples beat many mediocre ones
2. **Keep it current** - Update with recent content periodically
3. **Organize by type** - Makes it easier to find relevant references
4. **Include context** - Add notes about why content performed well
5. **Regular cleanup** - Remove outdated or low-quality references

## The More You Add, The Better

The 10X Content Expert analyzes your references to:
- Match your unique voice and style
- Extract insights and quotes
- Understand your key themes
- Generate on-brand content

Start with what you have, and add more over time!
